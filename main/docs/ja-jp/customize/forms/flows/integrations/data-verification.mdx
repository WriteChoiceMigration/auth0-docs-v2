# データ検証

このデータ検証アクションのリストは、メールアドレスを検証してワンタイムパスワードを生成・検証できるようにするものです。

## ワンタイムパスワードを生成する

メール、SMS、その他のメッセージアプリを使って送信できる、有効時間5分の数値コードを生成します。

<Frame>![](//images.ctfassets.net/cdy7uua7fh8z/1h69FWzZwk9beKKjB4Cq38/16aa515e61cc6e9ebdfd0849201e3141/generate-one-time-password.png)</Frame>

### 入力設定

<table class="table">
<thead>
<tr>
<th><b>パラメーター</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td>参照値（必須）</td>
<td>生成したコードは電話番号、メールアドレスや他の値にバインドできます。
          </td>
</tr>
<tr>
<td>コードの長さ（必須）</td>
<td>生成されたコードの桁数です。
          </td>
</tr>
</tbody>
</table>

### 出力オブジェクト

<table class="table">
<thead>
<tr>
<th><b>プロパティ</b></th>
<th><b>種類</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td><code>code</code></td>
<td>文字列</td>
<td>生成されたコードです。</td>
</tr>
</tbody>
</table>

### 出力オブジェクトの例

```json
{
  "code": "███",
}
```

## ワンタイムパスワードを検証する

提供したワンタイムパスワードコードが有効かどうかを検証します。

<Frame>![](//images.ctfassets.net/cdy7uua7fh8z/3bkT8QDN4dcl0YHTrSOIGj/9698a07f55353a11ca98164377cd4217/verify-otp.png)</Frame>

### 入力設定

<table class="table">
<thead>
<tr>
<th><b>パラメーター</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td>参照値（必須）</td>
<td>ワンタイムパスワード生成アクションで構成したのと同じ参照値を使用します。
</td>
</tr>
<tr>
<td>コードの長さ（必須）</td>
<td>生成されたコードの桁数です。
          </td>
</tr>
</tbody>
</table>

### 出力オブジェクト

<table class="table">
<thead>
<tr>
<th><b>プロパティ</b></th>
<th><b>タイプ</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td><code>有効</code></td>
<td>ブール値</td>
<td>指定されたコードが有効かどうかを示し、<code>true</code>または<code>false</code>の値を返します。</td>
</tr>
<tr>
<td><code>result</code></td>
<td>文字列</td>
<td>指定されたコードに基づき、以下のように異なる結果コードを返します。
            <ul> <li> <code>MISSING（欠落）：</code> コードが指定されていません。</li>
<li> <code>EXPIRED（有効期限切れ）：</code> 指定されたコードは有効期限切れです。</li>
<li> <code>VALID（有効）：</code> 指定されたコードは有効です。</li>
<li> <code>UNEQUAL（不一致）：</code> 指定されたコードは無効です。</li>
</ul></td>
</tr>
</tbody>
</table>

### 出力オブジェクトの例

```json
{
  "valid": false,
  "result": "UNEQUAL"
}
```

```json
{
  "valid": true
}
```

## メールアドレスの検証

提供されたメールアドレスに対して、選択されたいくつかの検証ルールを実行します。

<Frame>![](//images.ctfassets.net/cdy7uua7fh8z/6qkqny1hhObFalHwdEG342/1a2e18195b29102c3f68744f42277917/verify-email.png)</Frame>

### 入力設定

<table class="table">
<thead>
<tr>
<th><b>パラメーター</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td>Email（メール）（必須）</td>
<td>確認するメールアドレスです。
          </td>
</tr>
<tr>
<td>（MXレコードを必須にする）</td>
<td>MXレコードを必須にします。ドメインにMXレコードがない場合、メールサーバーはそのドメインに対してメールの送信先を判断できません。
          </td>
</tr>
<tr>
<td>Block free email providers（無料メールプロバイダーをブロックする）</td>
<td>@gmail.comや@hotmail.comなどの無料メールプロバイダーをブロックします。
          </td>
</tr>
<tr>
<td>Block disposable email providers（使い捨てメールプロバイダーをブロックする）</td>
<td>@mailnator.comや@maildrop.ccなどの使い捨てメールプロバイダーをブロックします。</td>
</tr>
<tr>
<td>Block email account aliases（メールアカウントのエイリアスをブロックする）</td>
<td>jane.doe+alias@gmail.comなど、メールアカウントのエイリアスをブロックします。</td>
</tr>
<tr>
<td>Allowlist domains（許可リストのドメイン）</td>
<td>リストにある承認されたドメインからのメールのみを許可します。</td>
</tr>
<tr>
<td>Blocklist domains（ブロックリストのドメイン）</td>
<td>特定のメールドメインをブロックします。</td>
</tr>
</tbody>
</table>

### 出力オブジェクト

<table class="table">
<thead>
<tr>
<th><b>プロパティ</b></th>
<th><b>種類</b></th>
<th><b>説明</b></th>
</tr>
</thead>
<tbody>
<tr>
<td><code>valid</code></td>
<td>ブール値</td>
<td>メールが検証ルールを満たしたかによって、<code>true</code>または<code>false</code>を返します。</td>
</tr>
<tr>
<td><code>cause</code></td>
<td>文字列</td>
<td>有効なプロパティが<code>false</code>の場合は、そのメールが満たしていない最初のルールについて以下の参照を返します。
            <ul> <li> <code>MISSING_MX_RECORD</code>：メールのドメインにMXレコードがありません。</li>
<li> <code>FREE_EMAIL</code>：メールのドメインが無料メールプロバイダーです。</li>
<li> <code>DISPOSABLE_EMAIL</code>：使い捨てメールアドレスです。</li>
<li> <code>BLOCKLISTED</code>：メールのドメインがブロックリストのドメイン設定に含まれています。</li>
<li> <code>NOT_ALLOWED</code>：メールのドメインが許可リストのドメイン設定に含まれていません。</li>
</ul></td>
</tr>
</tbody>
</table>

### 出力オブジェクトの例

```json
{
  "valid": false,
  "cause": "FREE_EMAIL"
}
```

```json
{
  "valid": true,
  "cause": null
}
```
