# アクショントリガー：pre-user-registration - Eventオブジェクト

pre-user-registrationアクショントリガーの`event`オブジェクトは、新規ユーザーの登録要求に関するコンテキスト情報を提供します。

<table class="table">
<thead>
<tr>
<th>プロパティ</th>
<th>説明</th>
</tr>
</thead>
<tbody>
<tr>
<td>
<p><code>event.client</code></p>
<p><em>（任意）</em></p>
</td>
<td>
<p>このトランザクションが開始されたクライアントについての
          情報。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>client_id</code> <em>文字列</em>。<span>ユーザーがログインしているアプリケーションのクライアントID。</span>
</li>
<li>
<code>metadata</code> <em>辞書</em>。<span>別のアプリケーションプロパティを保持するためのオブジェクト。</span>
</li>
<li>
<code>name</code> <em>文字列</em>。<span>アプリケーションの名前（Dashboardで定義された通り）。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.connection</code></p>
</td>
<td>
<p>ユーザー登録に使用された接続の詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>id</code> <em>文字列</em>。<span>接続の一意の識別子。</span>
</li>
<li>
<code>metadata</code> <em>任意の辞書</em>。<span>接続に関連したメタデータ。</span>
</li>
<li>
<code>name</code> <em>文字列</em>。<span>ユーザーの認証に使用される接続名（
              <code>twitter</code>または<code>some-g-suite-domain</code>など）。</span>
</li>
<li>
<code>strategy</code> <em>文字列</em>。<span>接続のタイプ。ソーシャル接続の場合、
              <code>event.connection.strategy === event.connection.name</code>。エンタープライズ接続では、
              <code>waad</code>（Microsoft Entra ID）、<code>ad</code>（Active
              Directory/LDAP）、<code>auth0</code>（データベース接続）など
              です。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.request</code></p>
</td>
<td>
<p>トランザクションを開始した要求の詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>body</code> <em>辞書</em>。<span>POST要求のボディ。このデータは、
              リフレッシュトークン、クライアント資格情報交換フロー、
              PreUserRegistrationアクション中のみ利用できます。</span>
</li>
<li>
<code>geoip</code> <em>オブジェクト</em>。<p>次のプロパティを含みます：</p>
<ul>
<li><code>cityName</code> <em>任意の文字列</em>。</li>
<li><code>continentCode</code> <em>任意の文字列</em>。</li>
<li><code>countryCode</code> <em>任意の文字列</em>。</li>
<li><code>countryCode3</code> <em>任意の文字列</em>。</li>
<li><code>countryName</code> <em>任意の文字列</em>。</li>
<li><code>latitude</code> <em>任意の数字</em>。</li>
<li><code>longitude</code> <em>任意の数字</em>。</li>
<li><code>subdivisionCode</code> <em>任意の文字列</em>。</li>
<li><code>subdivisionName</code> <em>任意の文字列</em>。</li>
<li><code>timeZone</code> <em>任意の文字列</em>。</li>
</ul>
</li>
<li><code>hostname</code> <em>任意の文字列</em>。<span>認証フローに使用されている
              ホスト名。</span>
</li>
<li>
<code>ip</code> <em>文字列</em>。<span>要求の発生元IPアドレス。</span>
</li>
<li>
<code>language</code> <em>任意の文字列</em>。<span>ブラウザーから要求された言語。</span>
</li>
<li>
<code>method</code> <em>文字列</em>。<span>要求に使用されたHTTPメソッド</span>
</li>
<li>
<code>user_agent</code> <em>任意の文字列</em>。<span>トランザクションの開始時に受け取った<code>User-Agent</code>の
              ヘッダーの値。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.tenant</code></p>
</td>
<td>
<p>現在のトランザクションに関連するテナントの詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>id</code> <em>文字列</em>。<span>テナント名。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.transaction</code></p>
<p><em>（任意）</em></p>
</td>
<td>
<p>現在のトランザクションについての詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>acr_values</code> <em>文字列の配列</em>。<span>元の認証要求に提供されたすべてのacr_values。
              </span>
</li>
<li>
<code>locale</code> <em>文字列</em>。<span>このトランザクションに使われるロケールで、
              ブラウザーの要求言語とテナントの言語設定を
              比較して決定される。</span>
</li>
<li>
<code>login_hint</code> <em>任意の文字列</em>。<span>エンドユーザーが必要な場合にログインに使用する可能性のある、
              ログイン識別子に関する認可サーバーへのヒント。</span>
</li>
<li>
<code>prompt</code> <em>任意の文字列の配列</em>。<span>ユーザーに再認証と同意を求めるかどうかを示す
              指示のリスト。</span>
</li>
<li>
<code>protocol</code> <em>任意の文字列</em>。<p>含まれる可能性のある値は以下の通りです：</p>
<ul>
<li>
<code>oidc-basic-profile</code>
<span>最も使用される、Webベースのログイン。</span>
</li>
<li>
<code>oidc-implicit-profile</code>
<span>モバイルデバイスおよびシングルページアプリで使用されます。</span>
</li>
<li>
<code>samlp</code> <span>SaaSアプリで使用されるSAMLプロトコール。</span>
</li>
<li>
<code>wsfed</code>
<span>Office365といったMicrosoft製品で使用されるWS-Federation
                  。</span>
</li>
<li>
<code>wstrust-usernamemixed</code>
<span>CRMおよびOffice365で使用されるWS-trustユーザー/パスワードログイン。</span>
</li>
<li>
<code>oauth2-device-code</code>
<span>デバイスの認可フローで使用されるトランザクション。</span>
</li>
<li>
<code>oauth2-resource-owner</code>
<span>通常、データベース接続に使用されるユーザー/パスワード
                  ログイン。</span>
</li>
<li>
<code>oauth2-resource-owner-jwt-bearer</code>

<li>
<code>oauth2-password</code>
<span>パスワード交換を使用したログイン。</span>
</li>
<li>
<code>oauth2-access-token</code>
<span>リフレッシュトークン交換を使用したトークンのリフレッシュ。</span>
</li>
<li>
<code>oauth2-refresh-token</code>
<span>リフレッシュトークン交換を使用したトークンのリフレッシュ。</span>
</li>
<li><code>oauth2-token-exchange</code></li>
<li>
<code>oidc-hybrid-profile</code>
<span>アクセストークンとリフレッシュトークンをアプリケーションが
                  安全に取得できるようにしながら、
                  IDトークンに即座にアクセスできるようにします。</span>
</li>
</ul>
</li>
<li><code>redirect_uri</code> <em>任意の文字列</em>。<span>トランザクションが完了した後にAuth0がリダイレクトするブラウザーのURL。
              </span>
</li>
<li>
<code>requested_scopes</code> <em>文字列の配列</em>。<span>この認証フローを開始するときに要求（必要ある場合）される
              スコープ。</span>
</li>
<li>
<code>response_mode</code> <em>任意の文字列</em>。<p>
              認可エンドポイントから返されたパラメーターに使用される
              認可サーバーのメカニズムに知らせます。</p>
<p>含まれる可能性のある値は以下の通りです：</p>
<ul>
<li><code>query</code></li>
<li><code>fragment</code></li>
<li><code>form_post</code></li>
<li><code>web_message</code></li>
</ul>
</li>
<li><code>response_type</code> <em>任意の文字列の配列</em>。<p>含まれる可能性のある値は以下の通りです：</p>
<ul>
<li><code>code</code></li>
<li><code>token</code></li>
<li><code>id_token</code></li>
</ul>
</li>
<li><code>state</code> <em>任意の文字列</em>。<span>Auth0がリダイレクトしてアプリケーションに戻る際に含まれ、
              アプリが初期要求に追加する不透明な
              任意の英数字の文字列。</span>
</li>
<li>
<code>ui_locales</code> <em>文字列の配列</em>。<span>元の認証要求で提供されたui_locales。
              </span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.user</code></p>
</td>
<td>
<p>登録を試みているユーザーを説明するオブジェクト。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>app_metadata</code> <em>任意の辞書</em>。<span>サポートプラン、セキュリティロール、アクセス制御グループなどの
              ユーザーアクセスに影響するユーザーについての情報を保存する
              カスタムフィールドです。</span>
</li>
<li>
<code>email</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーのメールアドレス。</span>
</li>
<li>
<code>family_name</code> <em>任意の文字列</em>。<span>ユーザーの姓。</span>
</li>
<li>
<code>given_name</code> <em>任意の文字列</em>。<span>ユーザーの名。</span>
</li>
<li>
<code>name</code> <em>任意の文字列</em>。<span>ユーザーの氏名。</span>
</li>
<li>
<code>nickname</code> <em>任意の文字列</em>。<span>ユーザーのニックネーム。</span>
</li>
<li>
<code>phone_number</code> <em>任意の文字列</em>。<span>ユーザーの電話番号。</span>
</li>
<li>
<code>picture</code> <em>任意の文字列</em>。<span>
<a href="https://auth0.com/docs/ja-jp/users/change-user-picture">ユーザーのプロファイル写真</a>を指すURL。</span>
</li>
<li>
<code>user_metadata</code> <em>任意の辞書</em>。<span>勤務先住所、自宅住所、ユーザーの設定など、
              ユーザーのアクセスに影響を与えないユーザーの情報を
              保存するカスタムフィールド。</span>
</li>
<li>
<code>username</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーのユーザー名。</span>
</li>
</ul>
</td>
</tr>
