post-user-registrationアクショントリガーの`event`オブジェクトは、新規作成されたユーザーに関するコンテキスト情報を提供します。

<table class="table">
<thead>
<tr>
<th>プロパティ</th>
<th>説明</th>
</tr>
</thead>
<tbody>
<tr>
<td>
<p>`event.connection`</p>
</td>
<td>
<p>ユーザーの登録に使用された接続についての詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>`id` <em>文字列</em>。<span>接続の一意の識別子。</span>
</li>
<li>
`metadata` <em>任意の辞書</em>。<span>接続に関連したメタデータ。</span>
</li>
<li>
`name` <em>文字列</em>。<span>ユーザー認証に使用される接続名（例：`twitter`または`some-g-suite-domain`）。</span>
</li>
<li>
`strategy` <em>文字列</em>。<span>接続のタイプ。ソーシャル接続の場合、`event.connection.strategy === event.connection.name`。エンタープライズ接続では、`waad`（Microsoft Entra ID）、`ad`（Active               Directory/LDAP）、`auth0`（データベース接続）などです。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p>`event.request`</p>
<p><em>（任意）</em></p>
</td>
<td>
<p>トランザクションを開始した要求の詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>`geoip` <em>オブジェクト</em>。<span>要求の地理情報を含みます。</span>
<p>次のプロパティを含みます：</p>
<ul>
<li>`cityName` <em>任意の文字列</em>。</li>
<li>`continentCode` <em>任意の文字列</em>。</li>
<li>`countryCode` <em>任意の文字列</em>。</li>
<li>`countryCode3` <em>任意の文字列</em>。</li>
<li>`countryName` <em>任意の文字列</em>。</li>
<li>`latitude` <em>任意の数字</em>。</li>
<li>`longitude` <em>任意の数字</em>。</li>
<li>`subdivisionCode` <em>任意の文字列</em>。</li>
<li>`subdivisionName` <em>任意の文字列</em>。</li>
<li>`timeZone` <em>任意の文字列</em>。</li>
</ul>
</li>
<li>`hostname` <em>任意の文字列</em>。<span>認証フローに使用されている
              ホスト名。</span>
</li>
<li>
`ip` <em>文字列</em>。<span>要求の発生元IPアドレス。</span>
</li>
<li>
`language` <em>任意の文字列</em>。<span>ブラウザーから要求された言語。</span>
</li>
<li>
`method` <em>文字列</em>。<span>要求に使用されたHTTPメソッド</span>
</li>
<li>
`user_agent` <em>任意の文字列</em>。<span>トランザクションの開始時に受け取った`User-Agent`のヘッダーの値。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p>`event.tenant`</p>
</td>
<td>
<p>現在のトランザクションに関連するテナントの詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>`id` <em>文字列</em>。<span>テナント名。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p>`event.transaction`</p>
<p><em>（任意）</em></p>
</td>
<td>
<p>現在のトランザクションについての詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>`acr_values` <em>文字列の配列</em>。<span>元の認証要求に提供されたすべての`acr_values`。
              </span>
</li>
<li>
`locale` <em>文字列</em>。<span>このトランザクションに使われるロケールで、ブラウザーの要求言語とテナントの言語設定を比較して決定される。</span>
</li>
<li>
`login_hint` <em>任意の文字列</em>。<span>エンドユーザーが必要な場合にログインに使用する可能性のある、ログイン識別子に関する認可サーバーへのヒント。</span>
</li>
<li>
`prompt` <em>任意の文字列の配列</em>。<span>ユーザーに再認証と同意を求めるかどうかを示す指示のリスト。</span>
</li>
<li>
`protocol` <em>任意の文字列</em>。<span>認証プロトコルについての情報を含みます。</span>
<p>可能性のある値には次のものが含まれます：</p>
<ul>
<li>
`oidc-basic-profile`
<span>最も使用されるWebベースのログイン。</span>
</li>
<li>
`oidc-implicit-profile`
<span>モバイルデバイスおよびシングルページアプリで使用されます。</span>
</li>
<li>
`samlp` <span>SaaSアプリで使用されるSAMLプロトコール。</span>
</li>
<li>
`wsfed`
<span>Office365といったMicrosoft製品で使用されるWS-Federation。</span>
</li>
<li>
`wstrust-usernamemixed`
<span>CRMおよびOffice365で使用されるWS-trustユーザー/パスワードログイン。</span>
</li>
<li>
`oauth2-device-code`
<span>デバイスの認可フローで使用されるトランザクション。</span>
</li>
<li>
`oauth2-resource-owner`
<span>通常、データベース接続に使用されるユーザー/パスワードログイン。</span>
</li>
<li>
`oauth2-resource-owner-jwt-bearer`

</li>
<li>
`oauth2-password`
<span>パスワード交換を使用したログイン。</span>
</li>
<li>
`oauth2-access-token`
<span>リフレッシュトークン交換を使用したトークンのリフレッシュ。</span>
</li>
<li>
`oauth2-refresh-token`
<span>リフレッシュトークン交換を使用したトークンのリフレッシュ。</span>
</li>
<li>`oauth2-token-exchange`</li>
<li>
`oidc-hybrid-profile`
<span>アクセストークンとリフレッシュトークンをアプリケーションが安全に取得できるようにしながら、IDトークンに即座にアクセスできるようにします。</span>
</li>
</ul>
</li>
<li>`redirect_uri` <em>任意の文字列</em>。<span>トランザクションが完了した後にAuth0がリダイレクトするブラウザーのURL。</span>
</li>
<li>
`requested_scopes` <em>文字列の配列</em>。<span>この認証フローを開始するときに要求（必要ある場合）されるスコープ。</span>
</li>
<li>
`response_mode` <em>任意の文字列</em>。<p> 認可エンドポイントから返されたパラメーターに使用される認可サーバーのメカニズムに知らせます。</p>
<p>含まれる可能性のある値は以下の通りです：</p>
<ul>
<li>`query`</li>
<li>`fragment`</li>
<li>`form_post`</li>
<li>`web_message`</li>
</ul>
</li>
<li>`response_type` <em>任意の文字列の配列</em>。<p>含まれる可能性のある値は以下の通りです：</p>
<ul>
<li>`code`</li>
<li>`token`</li>
<li>`id_token`</li>
</ul>
</li>
<li>`state` <em>任意の文字列</em>。<span>Auth0がリダイレクトしてアプリケーションに戻る際に含まれ、アプリが初期要求に追加する不透明な任意の英数字の文字列。</span>
</li>
<li>
`ui_locales` <em>文字列の配列</em>。<span>元の認証要求で提供された`ui_locales`。</span>
</li>
</ul>
</td>

<tr>
<td>
<p>`event.user`</p>
</td>
<td>
<p>
          現在のトランザクションが開始されたユーザーを表すオブジェクト。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>`app_metadata` <em>辞書</em>。<span>サポートプラン、セキュリティロール、アクセス制御グループなどのユーザーアクセスに影響するユーザーについての情報を保存するカスタムフィールドです。</span>
</li>
<li>
`created_at` <em>文字列</em>。<span>ユーザープロファイルが最初に作成された日時を示すタイムスタンプ。</span>
</li>
<li>
`email` <em>任意の文字列</em>。
            <span>（一意）ユーザーのメールアドレス</span>
</li>
<li>
`email_verified` <em>ブール値</em>。<span>ユーザーがメールアドレスを確認済みかどうかを示します。</span>
</li>
<li>
`family_name` <em>任意の文字列</em>。<span>ユーザーの姓。</span>
</li>
<li>
`given_name` <em>任意の文字列</em>。<span>ユーザーの名。</span>
</li>
<li>
`last_password_reset` <em>任意の文字列</em>。<span>ユーザーパスワードがリセット/変更された最終日時を示すタイムスタンプ。ユーザーの作成時に、このフィールドは存在しません。このプロパティは、データベース接続でのみ利用できます。</span>
</li>
<li>
`name` <em>任意の文字列</em>。<span>ユーザーの氏名。</span>
</li>
<li>
`nickname` <em>任意の文字列</em>。<span>ユーザーのニックネーム。</span>
</li>
<li>
`phone_number` <em>任意の文字列</em>。<span>ユーザーの電話番号。</span>
</li>
<li>
`phone_verified` <em>任意のブール値</em>。<span>ユーザーが電話番号を確認済みかどうかを示します。</span>
</li>
<li>
`picture` <em>任意の文字列</em>。<span><a href="/docs/ja-jp/users/change-user-picture">ユーザーのプロファイル写真</a>
              を指すURL。</span>
</li>
<li>
`updated_at` <em>文字列</em>。<span>ユーザーのプロファイルが最後に更新/変更された時を示すタイムスタンプ。</span>
</li>
<li>
`user_id` <em>文字列</em>。
            <span>（一意）ユーザーの一意の識別子。</span>
</li>
<li>
`user_metadata` <em>辞書</em>。<span>勤務先住所、自宅住所、ユーザーの設定など、ユーザーのアクセスに影響を与えないユーザーの情報を保存するカスタムフィールド。</span>
</li>
<li>
`username` <em>任意の文字列</em>。
            <span>（一意）ユーザーのユーザー名。</span>
</li>
</ul>
</td>
