# アクショントリガー：post-change-password - Eventオブジェクト

post-change-passwordアクショントリガーの`event`オブジェクトは、新規作成されたユーザーに関するコンテキスト情報を提供します。

<table class="table">
<thead>
<tr>
<th>プロパティ</th>
<th>説明</th>
</tr>
</thead>
<tbody>
<tr>
<td>
<p><code>event.connection</code></p>
</td>
<td>
<p>現在のトランザクションに使用された
          接続についての詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>id</code> <em>文字列</em>。<span>接続の一意の識別子。</span>
</li>
<li>
<code>metadata</code> <em>任意の辞書</em>。<span>接続に関連したメタデータ。</span>
</li>
<li>
<code>name</code> <em>文字列</em>。<span>ユーザーの認証に使用される接続名（
              <code>twitter</code>または<code>some-g-suite-domain</code>）。</span>
</li>
<li>
<code>strategy</code> <em>文字列</em>。<span>接続のタイプ。ソーシャル接続の場合、
              <code>event.connection.strategy === event.connection.name</code>。エンタープライズ接続では、
              <code>waad</code>（Microsoft Entra ID）、<code>ad</code>（Active
              Directory/LDAP）、<code>auth0</code>（データベース接続）など
              です。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.request</code></p>
</td>
<td>
<p>トランザクションを開始した要求の詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>geoip</code> <em>オブジェクト</em>。<span>要求の地理情報を含みます。<p>次のプロパティを含みます：</p>
<ul>
<li><code>cityName</code> <em>任意の文字列</em>。</li>
<li><code>continentCode</code> <em>任意の文字列</em>。</li>
<li><code>countryCode</code> <em>任意の文字列</em>。</li>
<li><code>countryCode3</code> <em>任意の文字列</em>。</li>
<li><code>countryName</code> <em>任意の文字列</em>。</li>
<li><code>latitude</code> <em>任意の数字</em>。</li>
<li><code>longitude</code> <em>任意の数字</em>。</li>
<li><code>subdivisionCode</code> <em>任意の文字列</em>。</li>
<li><code>subdivisionName</code> <em>任意の文字列</em>。</li>
<li><code>timeZone</code> <em>任意の文字列</em>。</li>
</ul>
</span></li>
<li><code>hostname</code> <em>任意の文字列</em>。<span>認証フローに使用されている
              ホスト名。</span>
</li>
<li>
<code>ip</code> <em>文字列</em>。<span>要求の発生元IPアドレス。</span>
</li>
<li>
<code>language</code> <em>任意の文字列</em>。<span>ブラウザーから要求された言語。</span>
</li>
<li>
<code>method</code> <em>文字列</em>。<span>要求に使用されたHTTPメソッド</span>
</li>
<li>
<code>user_agent</code> <em>任意の文字列</em>。<span>トランザクションの開始時に受け取った<code>User-Agent</code>の
              ヘッダーの値。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.tenant</code></p>
</td>
<td>
<p>現在のトランザクションに関連するテナントの詳細。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li><code>id</code> <em>文字列</em>。<span>テナント名。</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.user</code></p>
</td>
<td>
<p>
          現在のトランザクションが開始されたユーザーを表す
          オブジェクト。</p>
<p>次のプロパティを含みます：</p>
<ul>
<li>
<code>email</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーのメールアドレス。</span>
</li>
<li><code>email_verified</code> <em>任意のブール値</em>。<span>ユーザーがメールアドレスを確認済みかどうかを示します。
              </span>
</li>
<li>
<code>last_password_reset</code> <em>任意の文字列</em>。<span>ユーザーパスワードがリセット/変更された最終日時を示す
              タイムスタンプ。ユーザーの作成時に、このフィールドは存在しません。この
              プロパティはデータベース接続にのみ利用できます。</span>
</li>
<li>
<code>phone_number</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーの電話番号。</span>
</li>
<li>
<code>phone_verified</code> <em>任意のブール値</em>。<span>ユーザーが電話番号を検証済みかを示します。</span>
</li>
<li>
<code>user_id</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーの一意の識別子。</span>
</li>
<li>
<code>username</code> <em>任意の文字列</em>。
            <span>（一意）ユーザーのユーザー名。</span>
</li>
</ul>
</td>
</tr>
</tbody>
</table>
