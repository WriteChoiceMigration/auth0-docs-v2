# テナントログでパスキーイベントを監視する

[テナントログ](/docs/ja-jp/deploy-monitor/logs)を通じて、データベース接続に関連付けられたパスキー フローを監視できます。

<Tooltip data-tooltip-id="react-containers-DefinitionTooltip-0" tip="">Auth0 Dashboard</Tooltip>（[Monitoring（監視） > Logs（ログ）](https://manage.auth0.com/#/logs)）でログイベントを表示するか、[Management API](https://auth0.com/docs/api/management/v2/logs/get-logs)を使用してログを取得できます。

<table class="table"><thead>
<tr>
<th><strong>イベントコード</strong></th>
<th><strong>シナリオ</strong></th>
<th><strong>注釈</strong></th>
</tr>
</thead>
<tbody>
<tr>
<td><code>ss</code></td>
<td>サインアップで、ユーザーがパスキーを第一認証方式として登録した。</td>
<td>このログイベントには、エントリ値が<code>passkey</code>の<code>details.authentication_methods</code>配列フィールドが含まれます。<br/><br/>ユーザーがパスワードで登録した場合、この配列フィールドのエントリ値は<code>pwd</code>になります。</td>
</tr>
<tr>
<td><code>s</code></td>
<td>ログインで、ユーザーがパスキーを使って認証した。</td>
<td>このログインイベントには、ログインでユーザーがナビゲートした一連のプロンプトをリストする<code>details.prompts</code>配列が含まれます。<br/><br/>ユーザーがパスキーで認証した場合、配列は <code>"performed_amr": ["phr"]</code>フィールドのある要素を含みます。</td>
</tr>
<tr>
<td><code>gd_enrollment_complete</code></td>
<td>プログレッシブまたはローカルの登録フローが正常に完了した。</td>
<td>このログイベントには、ユーザーがパスキーを登録した場合、値が<code>passkey</code>の<code>details.authenticator.type</code>フィールドが含まれます。</td>
</tr>
<tr>
<td><code>gd_webauthn_enrollment_failed</code></td>
<td>プログレッシブまたはローカルの登録フローでエラーが発生した。</td>
<td>このログイベントには、ユーザーがパスキーで登録を試行した場合、エントリ値が<code>passkey</code>の<code>details.authentication_methods</code>配列フィールドが含まれます。</td>
</tr>
</tbody>
</table>
