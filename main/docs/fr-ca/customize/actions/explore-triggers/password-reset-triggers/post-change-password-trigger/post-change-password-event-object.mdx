# Déclencheurs d’action : post-change-password - Objet événement

L’objet `event` pour le déclencheur d’actions post-change-password fournit des informations contextuelles sur l’utilisateur nouvellement créé.

<table class="table">
<thead>
<tr>
<th>Propriété</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>
<p><code>event.connection</code></p>
</td>
<td>
<p>
          Information sur la connexion utilisée pour la transaction
          en cours.
        </p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>id</code> <em>Chaîne</em>.
            <span>L’identifiant unique de la connexion.</span>
</li>
<li>
<code>metadata</code> <em>Dictionnaire optionnel</em>.
            <span>Métadonnées associées à la connexion.</span>
</li>
<li>
<code>name</code> <em>Chaîne</em>.
            <span>Le nom de la connexion utilisée pour authentifier l’utilisateur (tel que :
              <code>twitter</code> ou <code>some-g-suite-domain</code>).</span>
</li>
<li>
<code>strategy</code> <em>Chaîne</em>.
            <span>Le type de connexion. Pour les connexions sociales,
              <code>event.connection.strategy === event.connection.name</code>.
              Pour les connexions d’entreprise, la stratégie est la suivante :
              <code>waad</code> (Windows Entra ID), <code>ad</code> (Active
              Directory/LDAP), <code>auth0</code> (connexions aux bases de données),
              etc.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.request</code></p>
</td>
<td>
<p>Détails sur la requête qui a initié la transaction.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>geoip</code> <em>Objet</em>.<span>Contient des informations géographiques sur la requête.
            <p>Comprend les propriétés suivantes :</p>
<ul>
<li><code>cityName</code> <em>Chaîne facultative</em>.</li>
<li><code>continentCode</code> <em>Chaîne facultative</em>.</li>
<li><code>countryCode</code> <em>Chaîne facultative</em>.</li>
<li><code>countryCode3</code> <em>Chaîne facultative</em>.</li>
<li><code>countryName</code> <em>Chaîne facultative</em>.</li>
<li><code>latitude</code> <em>Numéro facultatif</em>.</li>
<li><code>longitude</code> <em>Numéro facultatif</em>.</li>
<li><code>subdivisionCode</code> <em>Chaîne facultative</em>.</li>
<li><code>subdivisionName</code> <em>Chaîne facultative</em>.</li>
<li><code>timeZone</code> <em>Chaîne facultative</em>.</li>
</ul>
</span></li>
<li>
<code>hostname</code> <em>Chaîne facultative</em>.
            <span>Le nom d’hôte utilisé pour le flux
              d’authentification.</span>
</li>
<li>
<code>ip</code> <em>Chaîne</em>.
            <span>L’adresse IP d’origine de la requête.</span>
</li>
<li>
<code>language</code> <em>Chaîne facultative</em>.
            <span>La langue demandée par le navigateur.</span>
</li>
<li>
<code>method</code> <em>Chaîne</em>.
            <span>La méthode HTTP utilisée pour la requête</span>
</li>
<li>
<code>user_agent</code> <em>Chaîne facultative</em>.
            <span>La valeur de l’en-tête <code>User-Agent</code> reçu lors de l’initiation
              de la transaction.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.tenant</code></p>
</td>
<td>
<p>Détails sur le locataire associé à la transaction en cours.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>id</code> <em>Chaîne</em>.
            <span>Le nom du locataire.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.user</code></p>
</td>
<td>
<p>
          Objet décrivant l’utilisateur au nom duquel la transaction en cours
          a été initiée.
        </p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>email</code> <em>Chaîne facultative</em>.
            <span>(unique) Adresse courriel de l’utilisateur.</span>
</li>
<li>
<code>email_verified</code> <em>Booléen facultatif</em>.
            <span>Indique si l’utilisateur a vérifié son adresse
              courriel.</span>
</li>
<li>
<code>last_password_reset</code> <em>Chaîne facultative</em>.
            <span>Horodatage indiquant la dernière fois que le mot de passe de l’utilisateur a été
              réinitialisé/modifié. Lors de la création de l’utilisateur, ce champ n’existe pas. Cette
              propriété n’est disponible que pour les connexions aux bases de données.</span>
</li>
<li>
<code>phone_number</code> <em>Chaîne facultative</em>.
            <span>(unique) Numéro de téléphone de l’utilisateur.</span>
</li>
<li>
<code>phone_verified</code> <em>Booléen facultatif</em>.
            <span>Indique si l’utilisateur a vérifié son numéro de téléphone.</span>
</li>
<li>
<code>user_id</code> <em>Chaîne facultative</em>.
            <span>(unique) Identifiant unique de l’utilisateur.</span>
</li>
<li>
<code>username</code> <em>Chaîne facultative</em>.
            <span>(unique) Nom d’utilisateur de l’utilisateur.</span>
</li>
</ul>
</td>
</tr>
