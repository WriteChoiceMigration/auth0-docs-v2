# Déclencheurs d’action : credentials-exchange - Objet d’événement

L’objet `event` pour le déclencheur d’Actions d’échange d’identifiants fournit des informations contextuelles sur la demande d’échange d’identifiants d’un client.

<table class="table">
<thead>
<tr>
<th>Propriété</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>
<p><code>event.accessToken</code></p>
</td>
<td>
<p>Informations relatives au jeton d’accès à émettre.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li><code>customClaims</code> <em>Dictionnaire</em>.</li>
<li><code>scope</code> <em>Tableau de chaînes</em>.</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.client</code></p>
</td>
<td>
<p>Informations sur le client utilisé lors de cet échange de jetons.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>client_id</code> <em>Chaîne</em>.
            <span>L’ID client de l’application dans laquelle l’utilisateur se connecte.</span>
</li>
<li>
<code>metadata</code> <em>Dictionnaire</em>.
            <span>Un objet qui contient les autres propriétés d’une application.</span>
</li>
<li>
<code>name</code> <em>Chaîne</em>.
            <span>Le nom de l’application (tel que défini dans le Dashboard).</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.organization</code></p>
</td>
<td>
<p>Détails sur l’Organization associée à la transaction en cours.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>display_name</code> <em>Chaîne</em>.
            <span>Le nom amical de l’Organization.</span>
</li>
<li>
<code>id</code> <em>Chaîne</em>.
            <span>L’identifiant de l’Organization.</span>
</li>
<li>
<code>metadata</code> <em>Dictionnaire</em>.
            <span>Métadonnées associées à l’Organization.</span>
</li>
<li>
<code>name</code> <em>Chaîne</em>.
            <span>Le nom de l’Organization.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.request</code></p>
</td>
<td>
<p>Détails sur la requête qui a initié la transaction.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>body</code> <em>Dictionnaire</em>.
            <span>Le corps de la requête POST. Ces données ne seront disponibles
              que lors de l’actualisation du jeton, des flux d’échange de jetons de type identifiant client et
              de l’action de pré-enregistrement d’utilisateur.</span>
</li>
<li>
<code>geoip</code> <em>Objet</em>.
            <p>Comprend les propriétés suivantes :</p>
<ul>
<li><code>cityName</code> <em>Chaîne facultative</em>.</li>
<li><code>continentCode</code> <em>Chaîne facultative</em>.</li>
<li><code>countryCode</code> <em>Chaîne facultative</em>.</li>
<li><code>countryCode3</code> <em>Chaîne facultative</em>.</li>
<li><code>countryName</code> <em>Chaîne facultative</em>.</li>
<li><code>latitude</code> <em>Numéro facultatif</em>.</li>
<li><code>longitude</code> <em>Numéro facultatif</em>.</li>
<li><code>subdivisionCode</code> <em>Chaîne facultative</em>.</li>
<li><code>subdivisionName</code> <em>Chaîne facultative</em>.</li>
<li><code>timeZone</code> <em>Chaîne facultative</em>.</li>
</ul>
</li>
<li>
<code>hostname</code> <em>Chaîne facultative</em>.
            <span>Le nom d’hôte utilisé pour le flux
              d’authentification.</span>
</li>
<li>
<code>ip</code> <em>Chaîne</em>.
            <span>L’adresse IP d’origine de la requête.</span>
</li>
<li>
<code>language</code> <em>Chaîne facultative</em>.
            <span>La langue demandée par le navigateur.</span>
</li>
<li>
<code>method</code> <em>Chaîne de caractères</em>.
            <span>La méthode HTTP utilisée pour la requête</span>
</li>
<li>
<code>user_agent</code> <em>Chaîne facultative</em>.
            <span>La valeur de l’en-tête <code>User-Agent</code> reçu lors de l’initiation
              de la transaction.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.resource_server</code></p>
</td>
<td>
<p>
          Informations sur le serveur de ressources
          qui délivre le jeton d’accès.
        </p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>identifier</code> <em>Chaîne</em>.
            <span>L’identifiant du serveur de ressources. Par exemple :
              <code>https://your-api.example.com</code>.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.tenant</code></p>
</td>
<td>
<p>Informations sur le locataire utilisées lors de cet échange de jetons.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>id</code> <em>Chaîne</em>.
            <span>Le nom du locataire.</span>
</li>
</ul>
</td>
</tr>
<tr>
<td>
<p><code>event.transaction</code></p>
</td>
<td>
<p>Informations sur la transaction d’échange d’informations.</p>
<p>Comprend les propriétés suivantes :</p>
<ul>
<li>
<code>requested_scopes</code> <em>Tableau de chaînes</em>.
            <span>Les  permissions spécifiées (le cas échéant) lors de la demande du
               jeton d’accès.</span>
</li>
</ul>
</td>
</tr>
</tbody>
</table>
