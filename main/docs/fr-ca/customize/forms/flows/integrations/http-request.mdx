# Requête HTTP

## Configurer la connexion à votre coffre-fort

Pour configurer une connexion au coffre-fort pour vos actions de requête HTTP, vous aurez besoin d’un **jeton du porteur** :

<Frame>![Dashboard > Actions > Forms > Flows > Actions > HTTP Request ](//images.ctfassets.net/cdy7uua7fh8z/3X0Qbe9o1bx8q9ctxYZTO2/468b4d9b81bad93ab38b0b01dc773788/http-vault-connection.png)</Frame>

## Requête HTTP

L’action de requête HTTP vous permet d’appeler un service ou une API externe et de traiter la réponse.

<Frame>![](//images.ctfassets.net/cdy7uua7fh8z/6eIOv07XenyaazzKixigei/2e9efd632137829a8ddb03aacd3197df/http-request-action.png)</Frame>

### Paramètres de saisie

<table class="table">
<thead>
<tr>
<th><b>Paramètre</b></th>
<th><b>Description</b></th>
</tr>
</thead>
<tbody>
<tr>
<td>Méthode</td>
<td>
              La méthode HTTP. Les valeurs disponibles comprennent :
            <ul>
<li><code>GET</code></li>
<li><code>POST</code></li>
<li><code>PUT</code></li>
<li><code>PATCH</code></li>
<li><code>DELETE</code></li>
</ul>
</td>
</tr>
<tr>
<td>Type de contenu</td>
<td>
            L’en-tête <code>Content-Type</code>. Les valeurs disponibles comprennent :
            <ul>
<li><code>application/json</code></li>
<li><code>application/x-www-form-urlenconded</code></li>
<li><code>application/xml</code></li>
</ul>
</td>
</tr>
<tr>
<td>Corps</td>
<td>
              Le corps de la demande.	
          </td>
</tr>
<tr>
<td>En-têtes</td>
<td>
              En-têtes de la demande.	
          </td>
</tr>
<tr>
<td>Paramètres d’URL</td>
<td>
              Les paramètres d’URL. Ces paramètres seront automatiquement encodés URL.	
          </td>
</tr>
<tr>
<td>Activer l’authentification de base</td>
<td>
             Permet l’authentification avec nom d’utilisateur et mot de passe.
          </td>
</tr>
</tbody>
</table>

### Objet de sortie

<table class="table">
<thead>
<tr>
<th><b>Propriété</b></th>
<th><b>Type</b></th>
<th><b>Description</b></th>
</tr>
</thead>
<tbody>
<tr>
<td><code>headers</code></td>
<td>
              Objet
          </td>
<td>
              Les en-têtes de la réponse.
          </td>
</tr>
<tr>
<td><code>body</code></td>
<td>
              Objet
          </td>
<td>
              Le corps de la demande.
          </td>
</tr>
<tr>
<td><code>status</code></td>
<td>
              Nombre	
          </td>
<td>The code d’état de la réponse.</td>
</tr>
<tr>
<td><code>success</code></td>
<td>
             Booléen	
          </td>
<td>
            Renvoie <code>true</code> ou <code>false</code> basé sur le <code>status</code> de la réponse.	
          </td>
</tr>
</tbody>
</table>

### Exemple d’objet de sortie

```json
{
  "headers": {
    ...
  },
  "status": 200,
  "body": {
    ...
  },
  "success": true
}
```
