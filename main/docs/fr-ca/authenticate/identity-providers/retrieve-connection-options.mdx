# Récupérer les options de connexion

Vous pouvez récupérer l’objet d’options pour une [connexion](/docs/connections) à l’aide de <Tooltip data-tooltip-id="react-containers-DefinitionTooltip-0" tip="">Management API</Tooltip> Auth0.

Effectuez un appel `GET` au point de terminaison [Obtenir une connexion](/docs/api/management/v2#!/Connections/get_connections_by_id). Veillez à remplacer les valeurs d’espace réservé `CONNECTION_ID` et `MGMT_API_ACCESS_TOKEN` par votre ID de connexion et votre jeton d’accès à Management API, respectivement.

<CodeGroup>
```bash curl.sh
curl --request GET \
--url 'https://{yourDomain}/api/v2/connections/CONNECTION-ID?fields=options' \
--header 'authorization: Bearer MGMT_API_ACCESS_TOKEN'
```
```csharp c_.cs

IRestResponse response = client.Execute(request);
```
